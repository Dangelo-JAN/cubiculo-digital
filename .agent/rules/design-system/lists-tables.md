# 📋 Tablas y Listas

Actualmente no hay implementación de tablas complejas en Cubículo Digital.

## Componentes Existentes
- **StatCard**: Tarjetas de estadísticas en dashboard.
- **DeptCard**: Tarjetas de departamento con progreso.

## Patrón para futuras listas
- Usar grid de Tailwind (`grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3`).
- Bordes: `border-gray-200 dark:border-[#232f48]`.
- Hover: `hover:bg-gray-50 dark:hover:bg-[#1a2235]`.
